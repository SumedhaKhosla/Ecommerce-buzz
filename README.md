# 🛍️ Ecommerce-Buzz — Full Stack MERN E-Commerce Platform
------------------------------------------------
**Ecommerce-Buzz** is a dynamic e-commerce platform built using the **MERN stack** (MongoDB, Express.js, React.js, and Node.js). It comes packed with essential features like **JWT-based authentication**, **Redis caching**, **Cloudinary for media handling**, and **admin functionalities** to manage products and promotions efficiently.

## ✨ Highlights

### 🔐 User Authentication
- Secure user signup and login with password hashing
- Access and refresh token system using JWT
- Token blacklisting via Redis
- Protected routes for admin access

### 🛍️ Product Handling
- Admin can add or remove products
- Cloudinary integration for smooth image uploads
- Filter products by category
- APIs for featured and recommended listings

### ⚙️ Admin Control
- Mark/unmark products as "featured"
- Manage product and coupon data via admin-only routes

------------------------------------------------

## 🧱 Technologies Used

### Backend
- **Node.js** and **Express.js**
- **MongoDB** with **Mongoose**
- **Redis** (Upstash) for token/session management
- **JWT** and **Bcrypt** for authentication and password hashing
- **Cloudinary** for media uploads

### Frontend
- **React.js** (built with Vite)
- **Tailwind CSS** for responsive UI
- **Axios** for handling API calls
- **React Router DOM** for navigation
